# WRECKRUN: AFTERMATH

Играбельный браузерный 3D-прототип аркадной гонки на выживание. Проект сделан на Three.js и Vite, без внешних 3D-моделей: машины, уровни, персонажи и эффекты создаются процедурно.

## Что уже работает

- кампания из пяти районов с разной атмосферой, сложностью и наградой;
- три способа победить: завершить круги, разбить всех соперников или выполнить квоту;
- шесть машин с разными базовыми характеристиками;
- гараж: покупка машин, пять ступеней улучшения двигателя, брони и шасси, покраска;
- таран, пулемёт, ракеты и электрическая катушка;
- AI-соперники с разной агрессивностью;
- пешеходы с паникой и составным ragdoll;
- повреждения кузова, дым, искры, огонь, взрывы и частицы крови;
- нитро, миникарта, HUD, результаты заезда и сохранение прогресса в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
```

Готовая статика появится в `dist/`.

## Управление

- `WASD` или стрелки — газ, тормоз, поворот;
- `Shift` — нитро;
- `Space` — оружие;
- `R` — эвакуация на трассу со штрафом к корпусу;
- `Esc` — пауза.

## Техническая структура

- `src/main.js` — состояние кампании, гараж, генерация 3D-мира, физика, AI и эффекты;
- `src/styles.css` — интерфейс меню, гаража, кампании и HUD;
- `index.html` — точка входа Vite.

Это вертикальный срез: он задаёт игровой цикл и визуальное направление. Для production-версии следующим этапом стоит вынести системы в модули, подключить физический движок и заменить процедурные модели оптимизированными GLTF-ассетами.
